# ContentAI-PYME

**Grupo 07** — Plataforma web para generación contextualizada de contenido comercial para PYMES.

## Descripción general

ContentAI-PYME será una plataforma web diseñada para apoyar a pequeñas y medianas empresas en la creación, gestión y evaluación de contenido comercial mediante modelos de inteligencia artificial.

La aplicación permitirá que una empresa construya dentro de la plataforma un perfil digital de su negocio, registrando información relacionada con su actividad económica, productos, servicios, clientes, público objetivo, identidad de marca, campañas comerciales y canales de comunicación.

A partir de esta información, el sistema podrá generar diferentes tipos de contenido comercial utilizando modelos de lenguaje.

## Generación contextualizada

Una característica importante será que el sistema no utilizará solamente un prompt genérico, sino que podrá construir un contexto específico de la empresa antes de enviar la solicitud al modelo de IA.

### Ejemplo: productos agrícolas

Por ejemplo, una empresa que comercializa productos agrícolas podrá registrar sus productos, características, beneficios, público objetivo y tono de comunicación. Posteriormente podrá solicitar al sistema la generación de una publicación para redes sociales, una descripción de producto, un anuncio o un correo comercial.

### Ejemplo: servicio de mantenimiento

El usuario podrá seleccionar un producto o servicio y solicitar la generación de contenido:

> “Generar una publicación para redes sociales promocionando el nuevo servicio de mantenimiento preventivo de computadoras.”

La IA deberá utilizar la información registrada previamente por la empresa para generar contenido relacionado con el negocio.

## Tipos de contenido

El sistema podrá generar diferentes tipos de contenido:

- Publicaciones para redes sociales.
- Descripciones de productos.
- Anuncios.
- Textos promocionales.
- Mensajes para campañas.
- Títulos.
- Llamadas a la acción.

## Revisión y almacenamiento

El usuario podrá revisar el contenido generado, modificarlo, aprobarlo o descartarlo.

La aplicación deberá almacenar las versiones generadas para que posteriormente pueda analizarse qué tipo de estrategia produjo mejores resultados.

## Información que se podrá registrar

La aplicación permitirá registrar información como:

- Información de la empresa.
- Información de los productos.
- Información de los servicios.
- Público objetivo.
- Identidad de la marca.
- Campañas comerciales.

## Contenido que se podrá generar

La aplicación podrá permitir generar contenido como:

- Publicaciones para redes sociales.
- Descripciones de productos.
- Descripciones de servicios.
- Anuncios publicitarios.
- Correos comerciales.
- Artículos.
- Mensajes promocionales.
- Textos para páginas web.
- Landing pages.
- Llamados a la acción.
- Ideas para campañas.
